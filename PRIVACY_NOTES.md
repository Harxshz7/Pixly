# Pixly Privacy Surface Summary

All processing in Pixly is local-first. The only network requests made by the extension are direct, user-initiated API calls to the user's explicitly configured AI provider (Anthropic or OpenAI) using their personal API key. These requests transmit only the specific content selected by the user for analysis (the selected text snippet, right-clicked image URL/data, or screen region captured via the box selection tool) along with the structured system prompt required to perform the analysis. No analytics, telemetry, identifiers, browsing history, or background data are collected or transmitted to any external servers or third parties; all history entries, settings, custom templates, and baseline usage counters remain strictly on the user's local device in `chrome.storage.local`.
