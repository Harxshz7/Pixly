# Pixly — Architectural Privacy & Data-Surface Summary

Pixly operates under an uncompromising, local-first engineering architecture. The extension initiates network connections strictly upon explicit, user-triggered actions (such as selecting text, right-clicking an image, or drawing a screen bounding box). All resulting requests are dispatched directly from the client browser to the user's explicitly configured AI provider (Anthropic or OpenAI) over secure TLS 1.3 using their personal API credentials.

Outbound payloads contain solely the user-designated snippet or pixel bitmap accompanied by structured system prompt instructions. Pixly incorporates zero third-party telemetry libraries, zero external analytics SDKs, and zero tracking servers. All operational logs (`pixly_event_log`), user settings, API keys, custom prompt templates, and historical analysis records remain exclusively on the user's local machine within Chrome's sandboxed storage (`chrome.storage.local`).
